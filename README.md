# CS Student Portfolio

A modern, visually appealing developer portfolio with a dark-mode first design, featuring dynamic fetching of GitHub projects. 

## 🚀 Features
- **Dynamic GitHub Projects**: Automatically fetches and categorizes public repositories via the GitHub API.
- **Modern UI**: Deep navy/charcoal background (`#0a0f1e`) with electric blue/cyan accents (`#00d4ff`).
- **Smooth Animations**: Powered by `framer-motion` for scroll-triggered slide-ups, hover effects, and a dynamic typewriter intro.
- **Glassmorphism UI**: Frosted glass project cards and beautiful glowing borders.
- **Particle Network Background**: A subtle, interactive constellation effect in the Hero section.

## 🛠️ Built With
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Formik (for Contact form if enabled)
- tsParticles

## 💻 Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
